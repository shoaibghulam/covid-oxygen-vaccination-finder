# Covid Oxygen & Vaccination Centre Finder

BS Computer Science thesis project — Federal Urdu University of Arts, Science & Technology, Karachi (2022).

A web application that connects Covid-19 patients with nearby **oxygen-cylinder suppliers** and **vaccination centres**, with live availability checks and reservations.

## Features
- Search suppliers and vaccination centres by location
- Live availability status for oxygen cylinders and vaccine slots
- Reservation flow for patients and families
- Admin panel for suppliers and centres to update stock and slots

## Stack
Python · Django · HTML / CSS · JavaScript · SQLite

## Run locally
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
